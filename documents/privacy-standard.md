# PMAC Privacy and Data Handling Standard
**DRAFT — FOR INTERNAL ADOPTION BEFORE LAUNCH**

1. Collect the minimum information necessary to evaluate applications and case enquiries.
2. Keep private submissions segregated from public records in the database.
3. Require authenticated administrator accounts subject to database role checks.
4. Enable Postgres row-level security and explicitly restrict privileges on exposed tables.
5. No private file attachments are accepted via the public website at this stage.
6. Publish a case only after an independent confidentiality, consent and privacy review.
7. Never expose Supabase service-role credentials or secret API keys to public source code.
8. Define a retention and deletion timetable before collecting sensitive evidence.
9. Implement a documented response process for security incidents and privacy requests.
10. Introduce server-side verification and anti-spam measures prior to general public launch.
11. Ensure appropriate real-world legal compliance for operation, data storage and personal information.
